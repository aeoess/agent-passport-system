# Papers

The papers in this directory are publication snapshots. They are kept as
published and are not updated to track the current implementation. The
`generate_*.py` files are the scripts that produced them.

`agent-social-contract.{md,html,pdf}` is the February 2026 Zenodo publication,
including the implementation and test counts reported at that time. The
`draft-pidlisnyi-aps-*.xml` files are the Internet-Draft revisions as submitted.

For the current implementation, see the repository README and the current release.
